# korovan

3D action web game inspired by the legendary 2004 brief.

Three playable factions (forest elves, palace guard, the Villain) on a 4-zone overworld map, with caravans to rob, dense LOD forests, a limb-and-wound system, and Daggerfall-lite economy.

Runs in the browser. No install.

See [PLAN.md](./PLAN.md) for the full product plan: vision, MVP scope, phased roadmap, tech stack pick, risks, and open decisions awaiting product sign-off.
